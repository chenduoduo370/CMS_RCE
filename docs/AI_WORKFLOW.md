## 触发器类型

| 标记 | 功能 | Worker | 参数 |
|------|------|--------|------|
| `##PORTSCAN##` | 仅端口扫描 | PortScanWorker | host, ports, timeout |
| `##FINGERPRINT##` | 仅指纹识别 | CSSMD5Worker | host, timeout |
| `##AUTOTEST##` | 完整渗透测试 | AutoTestWorker | host, cmd, do_port_scan, ports, port_timeout |

## 交互示例

### 场景1：仅端口扫描

```
用户:  "扫描 192.168.10.111 的 1-100 端口"

AI:    "请问是否只进行端口扫描，不进行漏洞利用？"

用户:  "是的，只扫描端口"

AI:    "请确认以下参数：
        - 目标: 192.168.10.111
        - 端口: [1,2,3,...,100]
        确认执行吗？"

用户:  "确认"

AI:    "##PORTSCAN##{"host":"192.168.10.111","ports":[1,2,3,...,100],"timeout":2}##END##"

执行:
  🔍 [权限检查] 检测到 ##PORTSCAN## 标记

```

## 权限控制流程

```
用户输入 → AI 回复 → 触发器检测 → 权限验证 → 执行

                    ┌─────────────────────────────────────┐
                    │         权限验证流程                 │
                    └─────────────────────────────────────┘

  1. 检查触发器标记
         │
         ▼
  2. 解析 JSON 参数
         │
         ▼
  3. 验证必填参数 (host)
         │
         ▼
  4. 检查是否为"高级功能"
         │                    ┌────────────────────────┐
         │                    │ 允许调用:              │
         ├──────────┐        │  - PortScanWorker      │
         │ 是高级功能 │        │  - CSSMD5Worker        │
         │          │        │  - AutoTestWorker      │
         │          │        └────────────────────────┘
         │          │
         ▼          ▼
      ✓ 通过    ✗ 拒绝
```

## 核心代码位置

| 功能 | 文件 | 方法 |
|------|------|------|
| AI 对话 | qianwen_worker.py | `run()` |
| 触发检测 | poc_gui.py | `_check_autotest_trigger()` |
| 参数解析 | poc_gui.py | `_parse_trigger_params()` |
| 端口扫描 | poc_gui.py | `_start_portscan_from_ai()` |
| 指纹识别 | poc_gui.py | `_start_fingerprint_from_ai()` |
| 渗透测试 | poc_gui.py | `_start_autotest_from_ai()` |
| 日志记录 | poc_gui.py | `_log_ai_exec()` |
