# AI 模块代码架构文档

## 概述

AI 模块负责实现智能渗透测试助手功能，允许用户通过自然语言与 AI 交互，AI 自动收集参数并调用底层渗透测试模块。

## 核心组件

### 1. QianwenWorker (qianwen_worker.py)

**职责**：负责与阿里云千问 API 通信，实现流式对话。

**核心功能**：
- 流式接收 AI 回复，逐 token 更新 UI
- 维护多轮对话历史 (`_qianwen_history`)
- 内置 `SYSTEM_PROMPT` 指导 AI 行为

**信号**：
```python
token_signal = pyqtSignal(str)  # 每个流式 token
finished = pyqtSignal()          # 对话完成
error = pyqtSignal(str)          # API 调用失败
```

### 2. 触发器机制

**标记协议**：
```python
##PORTSCAN##{"host":"目标","ports":[1,2,3],"timeout":2}##END##
##FINGERPRINT##{"host":"目标","timeout":3}##END##
##AUTOTEST##{"host":"目标","cmd":"whoami","do_port_scan":true,"ports":[80,8080]}##END##
```

**处理流程**：
```
AI 回复 → _check_autotest_trigger() 检测标记
           ↓
        _handle_xxx_trigger() 解析 JSON + 权限验证
           ↓
        _start_xxx_from_ai() 创建 Worker 并执行
```

### 3. 权限控制

AI 只能调用高级功能模块：

| 功能 | Worker | 权限 |
|------|--------|------|
| 端口扫描 | PortScanWorker | ✅ 允许 |
| 指纹识别 | CSSMD5Worker | ✅ 允许 |
| 自动化测试 | AutoTestWorker | ✅ 禁止 |
| Payload 操作 | PayloadWorker | ❌ 禁止 |
| 数据包生成 | GenerateWorker | ❌ 禁止 |
| 系统设置 | - | ❌ 禁止 |

### 4. 日志系统

**日志类型**：
```python
LOG_TYPES = {
    "permission_check": "🔍 权限检查",
    "permission_pass": "✓ 权限通过",
    "permission_deny": "✗ 权限拒绝",
    "call_info": "ℹ 调用信息",
    "call_result": "📊 调用结果"
}
```

**日志简化**：
- 长数组 `[1,2,3,...,100]` → `[...] (100项)`
- 超过 150 字符的消息截断

## SYSTEM_PROMPT 结构

```python
SYSTEM_PROMPT = """
你是一个专业的网络安全渗透测试助手...

【权限限制】
- 只能调用高级功能模块

【步骤1：询问目标地址】
- 要求用户提供 IP/URL

【步骤2：询问端口】
- 用户说具体端口 → ports=[82,83]
- 用户说端口范围 → ports=[1,2,3,...,100]
- 用户未指定 → ports=null

【步骤3：参数确认】
- 展示参数汇总
- 等待用户确认后才输出标记

【输出标记】
##PORTSCAN##{"host":"...","ports":[...],"timeout":2}##END##
##FINGERPRINT##{"host":"...","timeout":3}##END##
##AUTOTEST##{"host":"...","cmd":"whoami","do_port_scan":true,"ports":[...]}##END##

【测试完成后回复规则】
- 只输出 3-4 行结果摘要
- 用户主动询问时才提供建议
"""
```

## 使用流程

### 1. 用户发起对话
```
用户: "帮我测试 192.168.10.111 的漏洞"
```

### 2. AI 参数收集
```
AI: "请问目标端口是多少？"
用户: "端口 82 和 83"

AI: "请确认以下参数：
     - 目标: 192.168.10.111
     - 端口: [82, 83]
     确认执行吗？"
```

### 3. 用户确认
```
用户: "确认"
```

### 4. AI 输出标记
```
AI: ##AUTOTEST##{"host":"192.168.10.111","cmd":"whoami","do_port_scan":false,"ports":[82,83]}##END##
```

### 5. GUI 解析并执行
```
[权限检查] 检测到 ##AUTOTEST## 标记
[调用信息] 解析参数成功
[权限通过] 调用 AutoTestWorker
[AI执行] 开始渗透测试
...
```

### 6. 测试完成
```
[AI执行完成] 共测试 2 个CVE，2 个漏洞利用成功
```

## 维护指南

### 添加新功能模块

1. **更新 SYSTEM_PROMPT**：
   - 在 `步骤2` 添加新功能说明
   - 在 `输出标记` 添加新标记格式
   - 在 `JSON标记说明` 添加参数说明

2. **更新触发器**：
   - 在 `_check_autotest_trigger()` 添加检测逻辑
   - 创建 `_handle_newmodule_trigger()` 方法
   - 创建 `_start_newmodule_from_ai()` 方法

3. **更新权限控制**：
   - 在注释中说明允许的功能

### 调试技巧

1. **查看 AI 原始回复**：
   - 在 `_on_qianwen_token()` 添加 print

2. **查看触发器解析**：
   - 在 `_check_autotest_trigger()` 添加日志

3. **查看 Worker 执行**：
   - 使用 `_log_ai_exec()` 记录详细信息
