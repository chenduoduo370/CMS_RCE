# 端口范围处理优化

## 问题描述
用户可能会使用不同的方式指定端口：
- **具体端口**：「端口 82 和 83」、「8080, 8081」
- **端口范围**：「扫描 1-100」、「常用端口」
- **不确定**：「帮我扫扫看」

系统需要对不同的输入方式做出适当反应。

## 解决方案

### 三类处理方式

#### 1. 具体端口（明确指定）
当用户明确说出具体端口号时：
```
用户输入: 「测试 192.168.10.111 端口 82 和 83」
AI 反应: 直接确认，不需要扫描
JSON: ports=[82,83], do_port_scan=false
```

#### 2. 端口范围（需要澄清）
当用户提到范围时：
```
用户输入: 「扫描 192.168.10.111 的端口范围 1-100」
AI 反应: 询问用户是完整扫描还是指定具体端口
  选项1: 完整扫描 → do_port_scan=true, ports=null
  选项2: 指定端口 → 请用户列出具体端口，如「80,443,8080」
JSON（完整扫描）: do_port_scan=true, ports=null
JSON（指定端口）: ports=[80,443,8080], do_port_scan=false
```

#### 3. 不确定或默认（启用自动扫描）
当用户没有明确指定时：
```
用户输入: 「扫一下这个网站」
AI 反应: 询问是否需要扫描开放端口，或已知目标端口
JSON（扫描）: do_port_scan=true, ports=null
JSON（已知端口）: ports=[已知端口], do_port_scan=false
```

## SYSTEM_PROMPT 更新

### 步骤2：询问是否启用端口扫描或指定端口

**更新内容**：
```
  - 如果用户明确说了具体端口（如"端口 82 和 83"），则不需要扫描，直接指定 ports=[82,83]
  - 如果用户说了端口范围（如"扫描 1-100"），询问是否启用完整扫描还是指定具体端口列表
    * 完整扫描：设置 do_port_scan=true, ports=null（系统会扫描常用端口）
    * 具体端口：请用户确认要扫描的具体端口号（如 "80,443,8080"），然后设置 ports=[80,443,8080]
  - 如果用户没说端口，询问是否需要先扫描开放端口
```

### JSON标记说明：ports 字段详解

**更新内容**：
```
  - ports: 用户指定的端口列表，如 [82,83]；未指定或要扫描常用端口则填 null
    * 示例：[80] 或 [8080,8081,8082] 或 [22,80,443,3306]
    * 注意：如果用户说"范围 1-100"，应询问用户是要完整端口扫描还是指定具体端口
    * 完整扫描：设置 do_port_scan=true, ports=null
    * 指定端口：请用户列出具体端口号，如"80, 443, 8080"，然后设置 ports=[80,443,8080]
```

## 关键规则

✅ **明确指定端口** → 直接使用，不扫描
✅ **提到范围但不确定** → 询问用户选择方案
✅ **没有指定** → 询问是否启用扫描
✅ **始终避免假设** → 让用户明确确认

## 技术细节

### JSON 标记格式
```json
##AUTOTEST##{
  "host": "192.168.10.111",
  "cmd": "whoami",
  "do_port_scan": true/false,
  "ports": [具体端口列表] 或 null,
  "port_timeout": 2
}##END##
```

### 参数组合规则

| do_port_scan | ports | 含义 | 例子 |
|---|---|---|---|
| true | null | 自动扫描常用端口 | 不确定端口时 |
| false | [80,443] | 仅测试指定端口 | 已知端口时 |
| true | [22,80] | 先扫描，再重点测试 | 混合模式（需确认） |

### AutoTestWorker 行为
- 当 `do_port_scan=true` 且 `ports=null`：执行完整的端口发现
- 当 `ports` 非空：跳过端口扫描，直接对指定端口进行指纹识别
- 当 `do_port_scan=false` 且 `ports=null`：默认使用端口 80

## 优势

✨ **清晰的意图表达**：用户知道会发生什么
✨ **避免误操作**：不会意外扫描全部端口（1-65535）
✨ **灵活的选择**：支持快速（直接指定）和探索（自动扫描）两种模式
✨ **错误恢复**：即使用户说法模糊，AI 也会询问澄清
