## 第4章 关键技术 - AI验证流程图

### 图4.1 AI辅助漏洞验证流程图

```
┌──────────────────────────────────────────────────────────────┐
│                  Payload 执行                                 │
│              (发送HTTP请求到目标)                             │
└────────────────────┬─────────────────────────────────────────┘
                     │
          ┌──────────▼──────────┐
          │ 获取 HTTP 响应      │
          │ Get HTTP Response   │
          └──────────┬──────────┘
                     │
          ┌──────────▼──────────────────┐
          │ 响应预处理                   │
          │ - 提取响应体                 │
          │ - 截断过长内容              │
          │ - 编码转换                   │
          └──────────┬──────────────────┘
                     │
          ┌──────────▼──────────────────┐
          │ 构造 AI 验证请求            │
          │ - CVE ID                    │
          │ - Payload 内容              │
          │ - HTTP 响应文本             │
          └──────────┬──────────────────┘
                     │
          ┌──────────▼──────────────────┐
          │ 调用 GPT-4 API              │
          │ Call OpenAI API             │
          └──────────┬──────────────────┘
                     │
        ┌────────────┴────────────┐
        │ API 调用成功?           │
        └────┬──────────────┬────┘
             │ 否           │ 是
             ↓              ↓
        ┌─────────┐  ┌──────────────────┐
        │ 降级处理 │  │ 解析 JSON 响应   │
        │ Fallback│  │ Parse JSON       │
        │ 使用正则 │  └────────┬────────┘
        │ 匹配    │           │
        └────┬────┘  ┌────────▼────────┐
             │       │ 提取验证结果    │
             │       │ - is_vulnerable │
             │       │ - confidence    │
             │       │ - reason        │
             │       └────────┬────────┘
             │                │
             └────────┬───────┘
                      │
             ┌────────▼────────┐
             │ 置信度评估      │
             │ - 高 (80-100)   │
             │ - 中 (50-80)    │
             │ - 低 (0-50)     │
             └────────┬────────┘
                      │
             ┌────────▼────────┐
             │ 返回验证结果    │
             │ Return Result   │
             └─────────────────┘
```

**图4.1说明**：
- 从Payload执行获得HTTP响应开始
- 进行响应预处理（提取、截断、编码转换）
- 构造AI验证请求，包含CVE ID、Payload内容、响应文本
- 调用GPT-4 API进行语义分析
- 如果API调用失败，降级到传统正则匹配方法
- 解析API返回的JSON结果
- 进行置信度评估
- 返回最终的验证结果

│ 误报率       │ 15-20%       │ 3-8%         │

- AI方法的可维护性更高，无需维护复杂的规则库
